# 아벨학원 홈페이지 설정·배포 안내

| 기능 | 누가 쓰나 | 어디서 |
|---|---|---|
| 학원 소개·교육과정·학원 소식 | 누구나 | `index.html`, `about.html`, `programs.html` |
| 공지사항 (사진 포함) | 누구나 | `notices.html` |
| 입학 상담·특강 신청 | 누구나 | `contact.html` → 관리자 화면 **상담 신청서**에서 확인 |
| 회원가입·로그인 | 초4~고3 학생 (초4~중2는 보호자 동의 확인 후 사용) | `signup.html`, `login.html` (머리글 오른쪽 위) |
| 학생 전용 (보충 강의 · 클래스) | **로그인한 회원만** | `videos.html` → [보충 강의] 영상을 누르면 유튜브로 이동(시청 기록이 남음), [클래스] 내 클래스의 숙제 공지와 내 스탬프 (`videos.html#class`로 바로 열 수 있음) |
| 관리자 화면 | **관리자만** | `admin.html` (바닥글 맨 아래 작은 '관리자' 글자) |

로그인과 데이터 저장에는 구글의 **Firebase**(무료 요금제), 홈페이지 공개에는 **GitHub Pages**(무료)를 씁니다.
아래 순서대로 한 번만 하면 됩니다. (처음이면 40분 정도)

---

## 1단계. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 에 구글 계정으로 들어가 **프로젝트 추가**. (Google 애널리틱스는 꺼도 됩니다)
2. **Authentication → 시작하기 → 로그인 방법**에서 **이메일/비밀번호**를 사용 설정합니다.
3. **Firestore Database → 데이터베이스 만들기** → 위치는 **asia-northeast3 (서울)** → 프로덕션 모드로 시작.
4. Firestore의 **규칙** 탭을 열고, 이 폴더의 `firestore.rules` 내용을 통째로 붙여 넣은 뒤 **게시**합니다.
   ⚠️ 이 단계를 빼먹으면 가입·로그인·신청서 저장이 거부되거나, 반대로 아무나 데이터를 볼 수 있게 됩니다.
5. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱**에서 웹 앱(`</>`)을 추가합니다. (Firebase 호스팅은 체크하지 않아도 돼요)
   화면에 나오는 `firebaseConfig`의 값 6개를 복사해 둡니다.

## 2단계. `firebase-config.js` 채우기

내려받은 폴더에서 `firebase-config.js`를 메모장(맥은 텍스트 편집기)으로 열고,
`apiKey: ""` 같은 빈 따옴표 안에 1단계에서 복사한 값을 하나씩 넣고 저장합니다.

```js
export const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "abel-academy.firebaseapp.com",
  projectId: "abel-academy",
  storageBucket: "abel-academy.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

(GitHub에 올린 뒤 GitHub 화면에서 고쳐도 됩니다 — 아래 "홈페이지 고치는 법" 참고)

## 3단계. GitHub에 파일 올리기

1. <https://github.com> 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
3. **Repository name**에 영어로 이름을 적습니다. 예: `abel-academy`
   - 공개 범위는 **Public**으로 고릅니다. (무료 계정은 Public 저장소에서만 GitHub Pages를 쓸 수 있어요)
   - 나머지는 그대로 두고 **Create repository**를 누릅니다.
4. 새 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
5. 내려받은 zip 파일의 압축을 풀고, **폴더 안에 있는 파일 전부**를 선택해서 브라우저 화면으로 끌어다 놓습니다. (모든 파일이 폴더 없이 한곳에 있어서 **choose your files**로 골라도 돼요)
   - 바깥 폴더째 올리지 마세요. 저장소 첫 화면에 `index.html`이 바로 보여야 합니다.
   - 한 번에 100개까지, 파일 하나당 25MB까지 올릴 수 있어요. 이 홈페이지는 40개 정도라 한 번에 올라갑니다.
6. 아래쪽 **Commit changes**를 누릅니다.

## 4단계. GitHub Pages 켜기 (홈페이지 공개)

1. 저장소 위쪽 메뉴의 **Settings** → 왼쪽 메뉴 **Pages**를 누릅니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 고릅니다.
3. **Branch**에서 `main`, 폴더는 `/ (root)`를 고르고 **Save**를 누릅니다.
4. 1~2분(길면 10분) 뒤 새로고침하면 Pages 화면 위쪽에 홈페이지 주소가 나옵니다.
   예: `https://내아이디.github.io/abel-academy/`
5. Firebase 콘솔 **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io`를 추가해 둡니다. (권장)

## 5단계. 관리자 2명 가입하기 — 공개하자마자 바로!

1. `홈페이지주소/admin.html` 에 들어갑니다. (홈페이지 바닥글 맨 아래 작은 **관리자** 글자를 눌러도 돼요)
2. **관리자 가입** 탭 → 이름·이메일·비밀번호를 넣고 **가입하기** → 바로 관리자 화면이 열립니다.
3. 두 번째 관리자(예: 부원장)도 같은 방법으로 가입하면 바로 관리자가 됩니다.
4. **세 번째부터는 '승인 대기'**가 되고, 기존 관리자가 관리자 화면 **관리자** 메뉴에서 **승인**해야 관리자가 됩니다.

⚠️ 처음 2자리를 비워 두면 주소를 아는 다른 사람이 먼저 관리자로 가입할 수 있어요. 홈페이지를 알리기 전에 2명을 먼저 가입해 두세요.
모르는 관리자가 보이면 **관리자** 메뉴에서 **관리자 해제**를 누르세요.

## 6단계. 잘 되는지 확인하기

- [ ] 홈 화면이 열리고, '학원 소식'에 "아직 올라온 소식이 없어요"가 보인다
- [ ] 관리자 화면 **공지 관리**에서 사진을 넣어 공지를 올리면 홈 '학원 소식'과 '공지사항' 페이지에 보인다
- [ ] 입학 상담 페이지에서 시험으로 신청하면 관리자 화면 **상담 신청서**에 들어온다 (확인 후 삭제)
- [ ] 회원가입 → 학생 전용 → 보충 강의에서 영상 목록이 보인다
- [ ] 관리자 화면 **학생 관리 → 클래스**에서 클래스를 만들고 학생을 넣은 뒤 스탬프·숙제를 올리면, 그 학생의 학생 전용 → 클래스에 보인다
- [ ] 관리자 화면 **보충 강의 관리**에서 유튜브 주소를 등록하면 학생 화면에 보인다
- [ ] 학생 아이디로 관리자 로그인을 하면 막힌다

## 홈페이지 고치는 법 (GitHub에서)

- 글자 하나 고치기: 저장소에서 파일 클릭 → 오른쪽 위 **연필(Edit)** → 고치기 → **Commit changes** → 1~2분 뒤 홈페이지에 반영.
- 파일 바꾸기: **Add file → Upload files**로 같은 이름의 파일을 올리면 덮어써집니다.
- 바뀐 내용이 안 보이면 브라우저에서 새로고침(Ctrl+F5, 맥은 Cmd+Shift+R)하세요.

## (선택) Netlify로 배포해서 신청 알림 메일 받기

GitHub Pages에서는 신청서가 관리자 화면에만 쌓이고 메일은 오지 않아요.
새 신청을 메일로 받고 싶다면 GitHub에 올린 저장소를 Netlify에 연결하면 됩니다.

1. <https://app.netlify.com> → **Add new project → Import an existing project → GitHub** → 저장소 선택 → 배포.
2. **Forms → Enable form detection**을 켜고, **Deploys**에서 한 번 다시 배포합니다.
3. **Forms → Submission notifications**에 알림 받을 이메일을 등록합니다.
4. 사이트가 비공개로 만들어졌다면 **Make public**으로 공개합니다.
5. Firebase **승인된 도메인**에 Netlify 주소(예: `abel-academy.netlify.app`)를 추가합니다.

Netlify를 쓰게 되면 `privacy.html` 6항에 Netlify(신청서 알림 메일) 위탁 내용을 추가해야 해요.

## 자주 묻는 것

- **아무나 회원가입해서 영상을 볼 수 있나요?** 중3~고3은 가입하면 바로 볼 수 있어요. 학원생이 아닌 회원은 학생 관리에서 **사용 중지**하세요.
- **초등학생·중1~중2는 왜 바로 못 쓰나요?** 만 14세 미만 아동의 개인정보는 법정대리인(보호자) 동의를 받아야 해서, 학원이 보호자께 전화로 동의를 확인한 뒤 '동의 확인'을 눌러야 쓸 수 있어요.
- **공지 사진은 어디에 저장되나요?** 줄인 사진을 Firebase 데이터베이스에 저장해요. Firebase의 사진 저장소(Storage)는 유료 요금제에서만 쓸 수 있어서 이렇게 무료로 운영해요.
  유튜브 '일부 공개' 영상은 주소를 아는 사람은 누구나 볼 수 있으니, 주소를 밖에 공유하지 않도록 안내해 주세요.
- **시청 내역은 정확한가요?** 학생이 홈페이지에서 영상을 눌러 유튜브로 연 기록이에요. 유튜브에서 끝까지 봤는지는 알 수 없어요.
- **관리자 비밀번호를 잊었어요.** 관리자 로그인 화면의 **비밀번호를 잊으셨나요?** → 가입한 이메일 입력 → 받은 메일의 링크에서 새 비밀번호를 정하세요. 메일이 안 오면 스팸함을 확인하세요. (Firebase 콘솔 **Authentication → 템플릿 → 비밀번호 재설정**에서 메일 언어를 한국어로, 보내는 사람 이름을 '아벨학원'으로 바꿀 수 있어요. **Authentication → 설정 → 승인된 도메인**에 `abel-academy.github.io`가 있으면 비밀번호를 바꾼 뒤 '계속' 버튼으로 관리자 화면에 돌아와요.)
- **학생이 비밀번호를 잊었어요.** 홈페이지에서는 다른 사람의 비밀번호를 바꿀 수 없어요. 기존 계정을 **사용 중지**하고 새 아이디로 다시 가입하도록 안내하세요.
- **회원 탈퇴 요청이 오면?** Firebase 콘솔 **Authentication → 사용자**에서 그 학생의 계정(아이디@students.example.com)을 삭제하고,
  **Firestore → students**에서 같은 사용자 UID의 문서를 삭제하세요. 접속·시청 기록(`logins`, `views`)에서도 그 학생 이름의 기록을 지워 주세요.
- **비용이 드나요?** GitHub Pages(Public 저장소)와 Firebase 무료(Spark) 요금제로 운영할 수 있는 규모예요.
  (Firebase 무료 한도: Firestore 저장 1GiB, 하루 읽기 5만·쓰기 2만 회)
- **`firebase-config.js`의 값이 공개돼도 되나요?** 네. 이 값은 공개용이고, 실제 보안은 `firestore.rules`가 지킵니다.
  대신 `STUDENT_EMAIL_DOMAIN` 값은 학생이 가입한 뒤에는 바꾸지 마세요.
- **학원 등록번호를 다시 넣어야 하나요?** 학원법상 인터넷으로 학습자 모집 광고를 할 때는 등록번호·학원 명칭·교습과목과 교습비등을 표시해야 해요.
  필요하면 각 페이지 바닥글의 주소 줄 아래에 `<div>학원 등록번호 제0000-00호</div>`처럼 한 줄 추가하면 됩니다.
- **개인정보 처리방침** (`privacy.html`)과 입학 상담 신청서의 [대괄호] 칸(보유 기간, 시행일, 보호책임자, Firebase 저장 위치 등)을 공개 전에 꼭 채워 주세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `firebase-config.js` | Firebase 연결 정보 (2단계에서 채움) |
| `firestore.rules` | Firebase 보안 규칙 (1단계에서 붙여 넣음) |
